# 브랜드 아이덴티티 (글로우 + 흑백 터미널)

2026-10-27, 사용자가 RobinX의 시작 화면에서 쓰는 **글로우와 흑백**을 자기 아이덴티티로 삼겠다고 해서 값을 규격으로 적었다.
RobinX뿐 아니라 이후 프로젝트·프로필·사이트에도 같은 언어를 쓴다. 파일은 [docs/brand/](brand/)에 있다.

## 한 줄로

**검정 바탕에 흰색과 회색만 쓰고, 화면에 하나뿐인 큰 요소(로고)만 흰 빛이 번지게 한다. 모든 것은 터미널처럼 `>` 프롬프트와 네모 커서로 말한다.**

## 로고

| 파일 | 쓰는 곳 |
|---|---|
| [`brand/wordmark-glow.svg`](brand/wordmark-glow.svg) | 글로우가 든 워드마크 (벡터, 투명 바탕). 검은 바탕 위에서만 보인다 |
| [`brand/wordmark.svg`](brand/wordmark.svg) | 글로우 없는 워드마크. 작은 크기나 글로우가 안 되는 곳 |
| [`brand/wordmark-glow-black.png`](brand/wordmark-glow-black.png) · [`-transparent.png`](brand/wordmark-glow-transparent.png) | 같은 것의 그림 (2960×1080). 검정 바탕 / 투명 |
| [`brand/logo-icon.svg`](brand/logo-icon.svg) · [`logo-icon-1024.png`](brand/logo-icon-1024.png) | 앱 아이콘(검은 타일 위의 R). 작업 표시줄·파비콘 |
| [`brand/avatar-glow.svg`](brand/avatar-glow.svg) · [`avatar-glow-1024.png`](brand/avatar-glow-1024.png) | 프로필 이미지 (검정 바탕, 글로우 R). 원형으로 잘려도 R이 남는다 |

- **워드마크:** 5줄 × 28칸의 픽셀 글자. 시작 화면의 글자(`src/components/startup-splash.tsx`의 `LOGO`)를 그대로 옮긴 것이다. 칸 사이에 가는 틈을 둔다.
  색은 위에서 아래로 `#ffffff` → `#9a9a9a` 한 번만 흐른다.
- **아이콘/프로필의 R:** 워드마크의 R과 같은 5×5 칸. 아이콘은 글로우 없이(작은 크기에서 번지면 흐려진다), 프로필은 글로우와 함께.
- **여백:** 로고 둘레에 글자 높이의 절반 이상. 글로우가 잘리지 않을 만큼 비운다.
- **하지 않는 것:** 색을 입히기, 흰색→회색 말고 다른 그라데이션, 둥글게 만들기, 다른 글꼴로 바꾸기, 글로우를 두 번 겹쳐 얹기, 밝은 바탕 위에 올리기(밝은 바탕에서는 `wordmark.svg`를 검정으로).

다시 만들려면 `node scripts/make-brand.mjs` (워드마크는 시작 화면 코드를 읽어 만들어서, 로고를 바꾸면 이 파일들도 같이 바뀐다).

## 색

색은 **검정, 흰색, 그 사이의 회색**뿐이다. 값은 [`brand/tokens.css`](brand/tokens.css).

| 역할 | 값 |
|---|---|
| 페이지 바탕 | `#070707` |
| 터미널 창 안쪽 · 로고 바탕 | `#0b0b0b` |
| 카드 | `#0e0e0e` |
| 본문 글자 | `#e8e8e8` |
| 제목·강조 | `#f2f2f2` / `#ffffff` |
| 보조 글자 | `#9e9e9e` (바탕에서 7:1 안팎) |
| 흐린 줄(로그 태그) | `#6f6f6f` (장식·큰 글자에만) |
| 선 | 흰색 14% (창 틀은 16%) |
| 상태 | 호박색 `#fbbf24`(NEW·직접 확인), 빨강 `#f87171`(지우기·실패). **이 둘만**, 상태를 알릴 때만 |

초록·파랑·보라 같은 색은 쓰지 않는다. 터미널 모양을 처음 만들 때 사용자가 "초록색으로바꾸지마 black and white 유지해"라고 했다.

## 글로우

- **흰색만.** 색이 있는 빛은 쓰지 않는다.
- 값은 시작 화면 로고가 쓰는 `drop-shadow(0 0 10px rgb(255 255 255 / 22%))`. 크게 키운 로고에는 `0 0 28px rgb(255 255 255 / 10%)` 한 겹을 더한다.
- **화면에 하나뿐인 큰 요소에만.** 로고, 한 화면의 주인공 글자 정도. 단추·카드·목록·본문에는 쓰지 않는다 (글로우가 흔해지면 아무것도 빛나지 않는다).
- 상자에는 `box-shadow`가 아니라 `filter: drop-shadow`를 쓴다. 칸 모양을 따라 번진다.
- 가끔 켜지는 것처럼 보여야 한다. 시작 화면에서는 로고가 한 줄씩(45ms 간격) 켜지며 빛난다.

참고: RobinX 소개 사이트는 "그림자·빛 번짐 없음"으로 만들어져 있다(2026-10-26). 사이트 첫 화면 제목에만 글로우를 넣을지는 따로 정한다.

## 글꼴

- **터미널(제목·로그·숫자·코드):** Cascadia Mono/Code → Consolas → D2Coding. 한글은 고정폭 글꼴에 없으므로 **Pretendard**로 그린다.
- **본문(긴 글):** Pretendard.
- 제목은 두껍게(700), 자간은 살짝 좁게(-0.02em). 본문은 400.

## 모양

- **모서리는 거의 각지게** `0.2rem`. 둥근 알약 모양은 쓰지 않는다. (앱 아이콘 타일만 둥글다: 플랫폼 아이콘 모양)
- **창은 터미널 창처럼**: 가는 흰 테두리(16%), 안쪽은 `#0b0b0b`.
- 제목은 프롬프트로 시작한다: `> 프로그램`. 끝에는 네모 커서(`█`)가 1초 박자로 깜빡인다. 깜빡임은 부드럽게 흐려지지 않고 켜졌다 꺼진다(`steps(1)`).
- 한 장면에만 **주사선**(3px마다 흰색 2.2%의 1px 줄)과 **가장자리 그늘**(가운데 55%까지 투명 → 가장자리 검정 55%)을 얹는다. 시작 화면이 그렇다. 모든 화면에 깔지 않는다.

## 움직임

- 빠르고 한 번에. 창 열림은 0.9→1배로 0.52초, 곡선은 `cubic-bezier(0.22, 1, 0.36, 1)`.
- 꺼질 때는 브라운관처럼 세로로 접혀 밝은 한 줄이 됐다가 가로로 사라진다 (0.42초).
- 글자는 치듯이 나타난다 (값을 3글자씩 빠르게 쳐 내려간다).
- **움직임 줄이기를 켠 사람에게는 움직임을 끈다** (`prefers-reduced-motion`). 이것은 예외가 없다.

## 말투

- 앱·사이트 글은 **해요체**. 로그 줄은 **명사형**으로 짧게: `설치된 프로그램 110개 (167ms)`, `최신 버전 사용 중`.
- 로그의 상태는 대괄호 태그: `[ OK ]` `[NEW]` `[SKIP]` `[FAIL]`. 인터넷이 없는 것처럼 앱 잘못이 아닌 것은 FAIL이 아니라 SKIP.
- 꾸밈말·감탄사·이모지를 쓰지 않는다. AI가 쓴 티가 나는 문장(대구, 맺음 문장)을 쓰지 않는다 (Humanizer 기준).

## 어디에 이미 쓰였나

- 시작 화면(`index.html`의 `.tty-*`, `src/components/startup-splash.tsx`): 글로우 워드마크, 주사선, 커서, `[ OK ]` 로그, 브라운관 꺼짐.
- 앱 "터미널" 모양(`src/index.css`의 `.terminal`), 소개 사이트(`website/`), 앱 아이콘(`src-tauri/app-icon.svg`).
