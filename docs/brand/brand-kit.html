브랜드 키트

검정 바탕에 흰색과 회색만 쓰고, 화면에 하나뿐인 큰 요소만 흰 빛이 번지게 한다. 모든 것은 터미널처럼 > 프롬프트와 네모 커서로 말한다.

로고

워드마크는 5줄 × 28칸의 픽셀 글자이고 시작 화면의 글자와 같다. 색은 위 #ffffff에서 아래 #9a9a9a으로 한 번만 흐른다. 단추를 누르면 내려받는다.

색

검정, 흰색, 그 사이의 회색뿐이다. 상태색은 호박색과 빨강 둘이고 상태를 알릴 때만 쓴다. 초록·파랑·보라는 쓰지 않는다. 누르면 값이 복사된다.

선은 흰색 14%(창 틀은 16%)이다.

글로우

시작 화면 로고가 쓰는 값이다. 흰색만, 두 겹까지.

R○ 이렇게화면에 하나뿐인 큰 요소 (로고)
× 이렇게 쓰지 않는다단추·카드·목록·본문에는 쓰지 않는다
  • 흰색만. 색이 있는 빛은 쓰지 않는다.
  • 화면에 하나뿐인 큰 요소에만. 글로우가 흔해지면 아무것도 빛나지 않는다.
  • 상자에는 box-shadow가 아니라 filter: drop-shadow를 쓴다. 칸 모양을 따라 번진다.
  • 가끔 켜지는 것처럼 보여야 한다. 시작 화면에서는 로고가 한 줄씩(45ms 간격) 켜지며 빛난다.
  • 한 장면에만 주사선(3px마다 흰색 2.2%의 1px 줄)과 가장자리 그늘을 얹는다. 모든 화면에 깔지 않는다. 이 페이지에서는 맨 위가 그 장면이다.
.brand-glow     { filter: drop-shadow(0 0 10px rgb(255 255 255 / 22%)); }
.brand-glow-big { filter: drop-shadow(0 0 10px rgb(255 255 255 / 22%))
                         drop-shadow(0 0 28px rgb(255 255 255 / 10%)); }

글꼴과 모양

터미널 · 제목, 로그, 숫자, 코드
> 프로그램 110개

Cascadia Mono / Code → Consolas → D2Coding. 한글은 Pretendard로. 제목은 700, 자간 -0.02em.

본문 · 긴 글
프로그램을 지운 뒤 남은 파일과 레지스트리를 찾아, 근거를 보고 고른 것만 백업한 뒤 정리해요.

Pretendard 400.

  • 모서리는 거의 각지게 0.2rem. 둥근 알약 모양은 쓰지 않는다 (앱 아이콘 타일만 둥글다).
  • 창은 터미널 창처럼. 가는 흰 테두리(16%), 안쪽은 #0b0b0b.
  • 제목은 프롬프트로 시작한다 (> 프로그램). 끝에는 네모 커서가 1초 박자로 깜빡이고, 흐려지지 않고 켜졌다 꺼진다.

>
  • 앱·사이트 글은 해요체. 로그 줄은 명사형으로 짧게. 상태는 대괄호 태그 [ OK ] [NEW] [SKIP] [FAIL].
  • 인터넷이 없는 것처럼 앱 잘못이 아닌 것은 FAIL이 아니라 SKIP.
  • 꾸밈말·감탄사·이모지를 쓰지 않는다. AI가 쓴 티가 나는 문장(대구, 맺음 문장)도 쓰지 않는다.
  • 움직임은 빠르고 한 번에. 창 열림은 0.9→1배로 0.52초, 곡선 cubic-bezier(0.22, 1, 0.36, 1). 꺼질 때는 브라운관처럼 세로로 접혀 밝은 한 줄이 됐다가 가로로 사라진다(0.42초). 글자는 치듯이 나타난다.
  • 움직임 줄이기를 켠 사람에게는 움직임을 끈다 (prefers-reduced-motion). 예외 없음.

tokens.css

새 프로젝트에 그대로 붙여 쓰는 값이다.

/*
 * 브랜드 토큰 (docs/BRAND.md). 새 프로젝트에 그대로 붙여 쓴다.
 * 값은 RobinX 앱·사이트의 실제 CSS에서 가져왔다 (index.html의 .tty-*, src/index.css의 .terminal.dark, website/src/index.css).
 */
:root {
  /* 바탕: 검정 둘. 페이지는 #070707, 그 위의 터미널 창(카드) 안쪽은 #0b0b0b */
  --brand-page: #070707; /* oklch(0.13 0 0) */
  --brand-term: #0b0b0b;
  --brand-card: #0e0e0e; /* oklch(0.165 0 0) */
  --brand-raised: #1b1b1b; /* oklch(0.22 0 0) 눌린 것·보조 면 */

  /* 글자: 흰색에서 회색까지. 색은 쓰지 않는다 */
  --brand-white: #ffffff; /* 로고 위쪽, 강조 */
  --brand-text: #e8e8e8; /* 본문 oklch(0.93 0 0) */
  --brand-text-strong: #f2f2f2; /* 제목·기본 단추 oklch(0.96 0 0) */
  --brand-text-dim: #9e9e9e; /* 보조 글 oklch(0.7 0 0), 바탕에서 7:1 안팎 */
  --brand-text-faint: #6f6f6f; /* 로그의 태그·흐린 줄 (큰 글자나 장식에만) */
  --brand-ink-bottom: #9a9a9a; /* 로고 아래쪽 (위 #ffffff → 아래 #9a9a9a) */

  /* 선: 흰색의 투명도 */
  --brand-border: rgb(255 255 255 / 14%);
  --brand-border-window: rgb(255 255 255 / 16%); /* 터미널 창 틀 */

  /* 상태색은 이 둘뿐 (상태를 알리는 때만, 장식으로 쓰지 않는다) */
  --brand-amber: #fbbf24; /* NEW·직접 확인 */
  --brand-red: #f87171; /* 지우기·실패 */

  /* 글로우: 흰색만, 두 겹. 로고와 화면에 하나뿐인 큰 요소에만 */
  --brand-glow-near: 0 0 10px rgb(255 255 255 / 22%); /* 시작 화면 로고가 쓰는 값 */
  --brand-glow-far: 0 0 28px rgb(255 255 255 / 10%); /* 크게 키운 로고에 한 겹 더 */

  /* 모양 */
  --brand-radius: 0.2rem; /* 거의 각지게 */
  --brand-ease: cubic-bezier(0.22, 1, 0.36, 1); /* ease-out-quint */

  /* 글꼴: 터미널은 고정폭, 한글은 Pretendard */
  --brand-font-term: "Cascadia Mono", "Cascadia Code", Consolas, "D2Coding", "Pretendard Variable", Pretendard, monospace;
  --brand-font-sans: "Pretendard Variable", Pretendard, -apple-system, "Segoe UI", sans-serif;
}

/* 글로우를 받는 요소: 글자나 SVG에는 filter, 상자에는 box-shadow가 아니라 filter를 쓴다 (칸 모양을 따라 번진다) */
.brand-glow {
  filter: drop-shadow(var(--brand-glow-near));
}
.brand-glow-big {
  filter: drop-shadow(var(--brand-glow-near)) drop-shadow(var(--brand-glow-far));
}

/* 터미널 창: 가는 흰 테두리, 안쪽은 더 어두운 검정. 주사선과 가장자리 그늘은 시작 화면 같은 한 장면에만 */
.brand-term {
  background: var(--brand-term);
  border: 1px solid var(--brand-border-window);
  border-radius: var(--brand-radius);
}
.brand-crt {
  position: relative;
}
.brand-crt::before,
.brand-crt::after {
  content: "";
  position: absolute;
  inset: 0;
  pointer-events: none;
}
.brand-crt::before {
  background: repeating-linear-gradient(to bottom, rgb(255 255 255 / 2.2%) 0 1px, transparent 1px 3px);
}
.brand-crt::after {
  background: radial-gradient(ellipse at center, transparent 55%, rgb(0 0 0 / 55%));
}

/* 깜빡이는 네모 커서: 1초 박자, 부드럽게 흐려지지 않고 켜졌다 꺼진다 */
.brand-cursor {
  display: inline-block;
  width: 0.6em;
  height: 1.15em;
  vertical-align: -0.2em;
  background: #e6e6e6;
  animation: brand-blink 1s steps(1) infinite;
}
@keyframes brand-blink {
  50% {
    opacity: 0;
  }
}
@media (prefers-reduced-motion: reduce) {
  .brand-cursor {
    animation: none;
  }
}
